Technical detail kept in reserve for the Q&A13 HEALTHACCESS
Use only if asked how the product works. Online uses Express 5 and TypeScript, with PostgreSQL 16 and Prisma. Offline is an independent Node service and worker using the same database and shared policy/crypto package; it does not call the online HTTP API. Africa's Talking provides SMS/USSD. This separation is useful for continuity, but is not a claim of operation without a network, database or provider. Redis, S3-compatible storage, AI providers and Firebase support other features. Secrets, monitoring and provider provisioning still require production work. Source: docs/architecture.md.
